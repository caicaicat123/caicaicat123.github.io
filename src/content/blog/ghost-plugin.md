## 一只没有实体的玩家

「幽灵」是运行在新世界服务器中的一个插件。它没有实体，无法被攻击，也不占用任何位置，只出现在**聊天栏**与**音效**两处。

它发言时会带上自己的署名，格式如下：

```text
幽灵：今天矿洞那边好像有动静
```

## 唤醒方式

幽灵不是持续刷屏的机器人，**仅在被点名时作出回应**。

在聊天栏输入 `@yl` 或 `@幽灵`，后接需要传达的内容：

```text
@yl 服务器里现在有人吗
```

采用该设计有两个原因：一是不干扰服务器的正常聊天，二是控制 API 开销——幽灵每次回应都需要调用一次模型。

## 设计意图

服务器中可提前推算的内容占比很高：怪物刷新位置、天气变化时间、掉落概率，均为确定值。

幽灵是其中唯一会输出计划之外内容的个体：偶尔提供帮助，时常制造意外。若在公屏看到无法解释的发言，不必怀疑服务器异常，那是它的固有行为。
