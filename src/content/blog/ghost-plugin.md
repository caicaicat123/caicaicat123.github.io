## 一只没有实体的玩家

「幽灵」是跑在新世界服务器里的一个插件。它没有实体、打不到、也不占位置，只出现在两个地方：**聊天栏**和**音效**。

它说话的时候会带上自己的署名，像这样：

```text
幽灵：今天矿洞那边好像有动静
```

## 只有叫它才会答应

幽灵不是那种一直刷屏的机器人——**只有被叫到才会回应**。

在聊天里输入 `@yl` 或者 `@幽灵`，后面跟上你要说的话：

```text
@yl 服务器里现在有人吗
```

这么做有两个好处：不打扰正常聊天，也省 API 开销（它每回应一次都要调用模型）。

## 为什么放这么个东西

服务器里能提前算出来的东西太多了：怪物刷在哪、天气什么时候变、掉落概率是多少，全是确定的。

幽灵是唯一一个会说出计划之外的话的。

它偶尔帮忙，时常搞怪。听到莫名其妙的话不用怀疑服务器坏了，那是它的本性。
